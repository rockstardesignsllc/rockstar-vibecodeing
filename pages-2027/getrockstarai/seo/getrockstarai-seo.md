# getrockstarai.com: titles, descriptions, keywords and schema

For each page in GHL:

1. **Page > Settings > SEO Meta Data**: paste the Title, Description and Keywords, and upload the matching image from the `getrockstarai/social-images/` folder as the **Social Image** (1200 x 630).
2. **Page > Settings > Tracking Code > Header Tracking Code**: paste the schema block. Copy the whole block, script tags included.

The slug and page table at the bottom matches each file to its GHL page.
