1. **Page > Settings > SEO Meta Data**: paste the Title, Description and Keywords, and upload the matching image as the **Social Image** (1200 x 630).
2. **Page > Settings > Tracking Code > Header Tracking Code**: paste the schema block. Copy the whole block, script tags included.

Pages 11 and 12 are a form page and a thank you page. Set both to **noindex** in GHL.

The slug and page table at the bottom matches each file to its GHL page.
